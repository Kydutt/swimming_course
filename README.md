Swimming Course Web

Deskripsi
Swimming Course Web merupakan aplikasi berbasis web yang dirancang untuk mempermudah proses pendaftaran dan pengelolaan data peserta kursus renang secara digital agar lebih efisien dan terorganisir.

Fitur Utama
-  Form pendaftaran peserta  
-  Menampilkan data peserta dalam bentuk tabel  
-  Halaman admin/dashboard  
-  Tampilan sederhana dan user-friendly  

Teknologi yang Digunakan
- HTML  
- CSS  
- JavaScript
